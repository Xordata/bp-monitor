# BpMonitor — дневник артериального давления с прогнозом НН

Трей-приложение для Windows (.NET Framework 4.8.1, один файл `BpMonitor.cs` ~3120 строк).
Ведёт дневник измерений АД, автоматически прикрепляет к записям погоду/геомагнитную активность/лекарства/контекст (эмоция, шум, сон), обучает небольшую нейросеть «на себе» и предупреждает, когда внешние условия похожи на те, при которых у вас росло давление.

Веб-интерфейс — одностраничник (`index.html`), отдаётся встроенным HTTP-сервером.

Веб-инструкция для пользователя — `help.html` (общая с сайтом bp.xor.world), доступна по `/help` и кнопкой «📖» в шапке.

## Быстрый старт

```
dotnet build
bin\Debug\net481\BpMonitor.exe
bin\Debug\net481\BpMonitor.exe --selftest   # самотест (временный каталог, данные не трогает)
```

Откроется иконка в трее. Интерфейс: **http://localhost:8090/**
- Двойной клик по трею (или клик, когда будильник не звенит) — открыть интерфейс.
- Клик по трею во время звена будильника — остановить звук.
- Порт, широта/долгота и прочее — вкладка «Настройки» (смена порта требует перезапуска).

## Возможности

### Измерения
- Добавление/правка/удаление записей АД (систолическое/диастолическое/пульс, заметка, принятые лекарства).
- При записи автоматически прикрепляется снимок: погода (давление мм рт.ст., температура, влажность, явление), Kp-индекс, эмоция/шум/сон из «Журнала», лекарства.
- **История**: фильтры по датам/значениям/только с лекарствами, график АД по фильтру, экспорт CSV/Excel.
- Ввод задним числом: для записей старше 2 часов погода и Kp подтягиваются из архива за этот момент.

### Погода и космос
- Текущая погода: **мет.служба Норвегии** [api.met.no](https://api.met.no) (`WxSource="metno"`, по умолчанию; работает и напрямую, и через прокси/Tor), опционально [open-meteo](https://open-meteo.com) (`WxSource="openmeteo"`), обновление каждые `PollMin` минут.
- Kp-индекс (геомагнитная активность): [GFZ Potsdam](https://kp.gfz-potsdam.de); прогноз Kp на 3 дня: [NOAA SWPC](https://services.swpc.noaa.gov) (флаг «⚡Kp прогноз» в шапке при ожидаемом Kp≥5).
- Опциональное перекрытие датчиками Home Assistant (давление/температура/влажность/Kp).
- Архивная погода для старых дат: forecast API (последние 5 дней) / ERA5-архив open-meteo (глубже).
- Кнопка «Заполнить погоду» в настройках: дозаполняет пустые поля погоды у всех старых записей (эндпоинт также умеет принудительную перезапись `force_until`).
- Popup-предупреждение (раз в `PopupCooldownMin`), когда прогноз НН по текущей погоде выше вашей «нормы» — «похожие условия, измерьте давление».
- **Упреждающий popup**: модель прогоняется по почасовому прогнозу погоды и Kp на ближайшие 12 часов — балюн «измерьте давление через ~N часов» приходит заранее, почасовой прогноз виден на вкладке «Модель».

### Нейросеть «на себе»
- Двухслойный перцептрон (tanh/tanh/линейный выход), вход — 15 базовых признаков (часы, погода, Kp, эмоция/шум/сон, количество лекарств, **возраст и пол** пользователя) + 2 на каждое лекарство (ФК-модель: остаточная концентрация и положение в окне действия), выход — прогноз систолического/диастолического.
- Обучение при каждом вводе измерения (SGD) + кнопка «Генетическое обучение» (популяция, турнирный отбор, элитизм) — уходит из локальных минимумов.
- **Контроль качества**: «Проверить модель» переобучает НН с нуля без последних N записей и проверяет на них — MAE/RMSE по sys/dia, MSE обучение/holdout (флаг «возможен переобуч») и перестановочная значимость фич (какие факторы реально двигают прогноз).
- **Автоподбор гиперпараметров**: «Подобрать гиперпараметры» перебирает сетку размеров слоёв на holdout и применяет лучшую конфигурацию.
- Вкладка «Модель»: график потерь, прогноз на сейчас и почасовой прогноз на 12 ч, сброс/переобучение.
- Гиперпараметры (lr, размеры слоёв, эпохи) — в настройках; смена размеров применяется после «Сбросить модель».

### Будильники (напоминания измерять давление)
- Звук mp3 зацикленно, несколько будильников.
- Расписание: ежедневно / по дням недели / каждые N дней (якорь фиксируется при первом срабатывании).
- Напоминание «через N минут» балуном в трее; догон пропущенных в окне 30 минут.
- Полное редактирование прямо в таблице (время, подпись, расписание, вкл/выкл).

### Журнал контекста
- Эмоции (шкала −10…+10), шум/события (список типов настраивается), сон (часы + качество).
- Нейтральные значения по умолчанию во всех формах.
- Запись журнала засчитывается измерению, если сделана в окне до него (12 ч/3 ч/36 ч по типу) **или в течение 10 минут после** него.
- Импорт сна из CSV Mi Band / Mi Fit.

### Лекарства
- Список препаратов; для известных — справочные T½ и длительность действия из `medpk.json` рядом с exe (создаётся при первом запуске, правится в UI или редактированием файла — без пересборки), для неизвестных 8/12 ч; всё можно править.
- Используются НН как фармакокинетические признаки.
- **Расписание приёма** (по каждому лекарству, HH:MM через запятую) — балюн-напоминание «пора принять» с догоном 30 мин.
- **Отметки приёма** («✓ Принять») — журнал фактических приёмов (свой тип записей в `data.bin`); НН строит по ним PK-признаки, даже когда лекарство не отмечено на измерении.

## Данные (папка `data/` рядом с exe)

- `data.bin` — append-only журнал записей (магический заголовок `BPMN`, v2, строковый пул, тумстоуны удаления).
- `nn.bin` — веса нейросети (формат v3: два скрытых слоя).
- `config.json` — настройки.
- `data\logs\yyyyMMdd.log` — служебный лог (ошибки погоды/Kp/бэкапа/задач, ротация при >5 МБ).
- `data\validate.json` — последний результат holdout-валидации (MAE/RMSE + значимость фич).
- `data\tune.json` — последний результат автоподбора гиперпараметров.
- `backups\yyyyMMdd.zip` — автоматическая суточная резервная копия `config.json + data.bin + nn.bin` (при старте и раз в час, хранятся последние 30).

Компакция `data.bin` (убрать tombstone и копии правок): кнопка «Сжать базу» в настройках или `POST /api/storage/compact`.

Перенос на другой ПК одним файлом: `GET /api/export/all` — единый JSON (настройки + все данные + веса НН + справочник ФК); `POST /api/import/all` с полем `{"confirm":true}` — восстановление (перед заменой создаётся архив `backups\preimport-*.zip`). Кнопки в настройках.

## Синхронизация с bp.xor.world (Фаза 7)

Десктоп — offline-first: локальный append-журнал авторитетен для своих записей, сервер — арбитр порядка (его seq). Включается галкой «Синхронизация» в настройках (по умолчанию выкл).

- **Токен**: персональный API-токен создаётся в веб-настройках bp.xor.world в разделе «Устройства», показывается один раз. Вписывается в поле «Токен». Утечка токена не даёт пароль от почты и токен можно отозвать.
- **Интервал**: фоновый таймер (по умолчанию 15 мин) + сразу после локальной записи + при старте. Сеть пропала — тихо копим, следующий цикл догонит (дельта по seq).
- **Merge**: last-writer-wins по серверному seq. Удаление = tombstone по Guid, реплицируется. Echo-подавление: полученные с сервера записи (диапазоны в `data/sync.json`) обратно не отправляются.
- **Конфиг** — односторонний: «десктоп главный» (push перезаписывает серверный) или «сервер главный» (pull отдаёт серверный). Двустороннего merge конфига нет.
- **Первый пуск**: при пустом сервере локальная база авто-загружается целиком (тот же путь, что export/all, но построчно через push).
- Курсоры и диапазоны — `data/sync.json`. Балюн-индикатор только при ошибке авторизации (отозванный/неверный токен), не при каждой синхронизации.
- API: `GET /api/sync/status`, `POST /api/sync/now` (принудительный цикл).

## API (все POST принимают JSON, сервер слушает только localhost + проверяет same-origin)

| Метод | Назначение |
|---|---|
| `GET /api/state` | всё состояние: cfg, измерения, журнал, НН, погода |
| `POST /api/measurement` | добавить измерение `{t,sys,dia,pulse,note,meds[]}` |
| `POST /api/measurement/update` | правка (тот же набор + `id`) |
| `POST /api/measurement/delete` | `{id}` |
| `POST /api/emotion` / `/api/noise` / `/api/sleep` | записи журнала |
| `POST /api/journal/delete` | `{id}` |
| `POST /api/sleep/import` | CSV Mi Band |
| `POST /api/medtake` | отметить приём лекарства `{med, t?}` (t по умолчанию — сейчас) |
| `POST /api/medtake/delete` | `{id}` |
| `POST /api/medpk` | полная замена справочника ФК `{"entries":{"имя":[T½,длительность],...}}` → `medpk.json` |
| `GET /api/nn/predictions` | прогноз НН по каждой записи |
| `POST /api/nn/train` / `/api/nn/train_ga` / `/api/nn/reset` | обучение SGD / генетическое / сброс |
| `POST /api/nn/validate` | holdout-валидация (фоновая задача): обучение без последних N записей, MAE/RMSE + перестановочная значимость фич; опционально `{"holdout":N}` |
| `POST /api/nn/tune` | автоподбор размеров слоёв (фоновая задача): сетка 3×3 на holdout, лучшая применяется; опционально `{"holdout":N}` |
| `GET /api/export/all` | экспорт всего одним JSON (cfg + данные + НН + medpk), файл-вложение |
| `POST /api/import/all` | импорт из файла экспорта (требует `confirm:true`; автобэкап перед заменой) |
| `GET /api/job` | статус фоновой задачи (train_ga/validate/tune/backfill): running, name, done/total, result, error |
| `POST /api/weather/refresh` | опросить погоду сейчас |
| `POST /api/weather/backfill` | дозаполнить погоду (фоновая задача, прогресс в `/api/job`); опционально `{"force_until":"ISO-дата"}` — принудительная перезапись до даты |
| `POST /api/storage/compact` | компакция `data.bin` (переписать из текущего состояния, убрать tombstone/копии правок) |
| `POST /api/config` | сохранение конфига (merge: присланные поля заменяются, остальные сохраняются) |
| `POST /api/autostart` | `{on}` — автозапуск из реестра |
| `POST /api/alarm/test` / `/api/alarm/stop` | звук будильника |
| `POST /api/export` | экспорт `{kind,fmt}` |
| `GET /api/version` | версия |

## Известные ограничения

- Только Windows (WinForms-трей + HttpListener/http.sys).
- Один пользователь на компьютере (синхронизация между устройствами — через bp.xor.world, см. выше).
- Архив погоды ERA5 отстаёт на ~5 суток; глубина forecast API ограничена.
